About This System

University One is a modern web-based portal system designed to provide students, faculty, and staff with convenient access to university services and data. This system represents a significant modernization effort to replace the traditional terminal-based interfaces with intuitive, web-enabled applications.

System Architecture

The system employs an API-First middleware architecture that bridges the gap between modern web interfaces and the legacy IBM AS/400 mainframe systems. This approach ensures:

  • Data Consistency: Single source of truth maintained on the DB2 database
  • Operational Continuity: Existing COBOL programs continue to operate
  • Scalability: Support for growing number of concurrent users
  • Security: Centralized authentication and authorization control
  • Maintainability: Clear separation of concerns between layers

Technical Details

  • Platform: IBM AS/400 (iSeries) with IBM i operating system
  • Database: DB2 for iSeries with comprehensive schema
  • API Layer: Secure gateway for data access and business logic
  • Frontend: HTML/JavaScript web interface
  • Access Pattern: ODBC gateway with connection pooling
